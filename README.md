# Lat2Cyr

A Firefox extension for converting Serbian Latin script to Cyrillic.

## Features

- **Popup Converter**: Convert between Serbian Latin and Cyrillic. Use the tabs to switch direction. In Latin mode, shortcut keys insert č, ć, đ, š, ž (⇧ for uppercase). Copy the result to clipboard. Input and direction are remembered between opens.
- **Context Menu**: Right-click on selected text in editable fields (inputs, textareas, contenteditable elements) and choose "Convert to Cyrillic" or "Convert to Latin".

## Usage

- Click the extension icon to open the popup.
- Pick a direction with the tabs (`Lat → Ćir` or `Ćir → Latin`).
- Type or paste text and see the conversion in real-time. Input and direction are remembered between opens.
- In Latin mode, use the shortcut keys to insert č, ć, đ, š, ž (⇧ for uppercase).
- Click Copy to Clipboard to copy the result.
- Or right-click selected text in an editable field and choose "Convert to Cyrillic" or "Convert to Latin".
